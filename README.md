## 🧼 Posting Hygiene & Rules

- **Tier 1:** Maximum reach - post first for any Keys-wide announcement
- **Tier 2:** Town-targeted or strong niche - match content to geography/topic
- **Tier 3:** Small or specialized - use only when content directly fits
- **Hygiene Guideline:** Stagger posts 10-15 min apart, vary opening line per group, check each group's promo rules

## ⚙️ How to Manage Groups

To add new groups or update existing records, use the included CLI management tool:
```bash
python3 manage_groups.py
```
This interactive script will update the [JSON file](group_research/florida_keys_facebook_subgroups.json) and automatically regenerate this `README.md` with sorted tables and clickable links.
