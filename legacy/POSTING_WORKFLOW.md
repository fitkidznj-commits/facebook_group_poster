# Florida Keys Facebook Posting Workflow

## Town Buckets And Group Identities

The canonical naming view is [TOWN_GROUP_IDENTITIES.md](TOWN_GROUP_IDENTITIES.md). Route by town first, then by group identity.

### Keys-Wide

Use for announcements that matter across the whole island chain, broad local business visibility, community posts, and large niche topics.

Primary:
- What's Up Florida Keys? LOCALS ONLY - community hub
- Florida Keys Fishing - fishing/marine, when the post is fishing, boating, seafood, charter, marina, tackle, lobster, or water-recreation related

Secondary:
- Florida Keys Events - events board, for public events
- Florida Keys Local Business information and advertising - business board, for business/promotional posts
- Keep It Local Florida Keys - business board, for local business posts
- Florida Keys Business Directory - business board, for business listings and service posts
- Keys Life (a place to share) - community hub, for softer community posts
- Florida Keys - Locals Only - community hub, for local-first non-spammy posts

Specialized:
- Florida Keys History with Brad Bertelli - history/culture, only for history or heritage content
- Florida Sargassum Reports + Daily News - environment/water, only for water/environment/sargassum content
- Upper Fl Keys Rentals and Florida Keys Forever Home - housing boards, only for housing
- South Dade and Upper Keys Homeschoolers - family/youth, only for family/education
- Upper Keys Wine Beer & Food Events - events board, only for food/drink events
- Pirates Saving Paradise Group - community cause, only for aligned community-cause posts

## Routing By Post Type

### Local Business Post

Start with:
- Florida Keys Local Business information and advertising
- Keep It Local Florida Keys
- Florida Keys Business Directory

Then add geography:
- Key Largo, FL Keys for Key Largo/Tavernier
- Islamorada, Florida for Islamorada
- Marathon, FL Keys Past|Present|Future- (uncensored) for Marathon/Middle Keys
- THINGS TO DO IN KEY WEST for Key West visitor-facing businesses

Use community groups only when the post is written like useful local news, not a hard ad.

### Restaurant, Bar, Food, Or Event Post

Start with:
- Florida Keys Events
- Upper Keys Wine Beer & Food Events, if Upper Keys food/drink event
- THINGS TO DO IN KEY WEST, if Key West or visitor-facing
- Key Largo and Islamorada Happenings, if Upper Keys event

Then add the relevant town groups.

### Fishing, Charter, Boating, Marina, Lobster, Or Seafood Post

Start with:
- Florida Keys Fishing
- Florida Lobster Mini Season and Regular, if lobster/diving/seasonal or strongly relevant
- Florida offshore fishing, if offshore focused

Then add geography:
- Key Largo, FL Keys
- Islamorada, Florida
- Experience the Islamorada Sandbar!, if boating/sandbar/tourism
- Marathon, FL Keys Past|Present|Future- (uncensored)

### Tourism Or Things-To-Do Post

Start with:
- Florida Keys Events
- THINGS TO DO IN KEY WEST, if Lower Keys/Key West
- Experience the Islamorada Sandbar!, if Islamorada water recreation
- Key Largo and Islamorada Happenings, if Upper Keys

Then add the relevant town group.

### Jobs Post

Use only:
- Upper Florida Keys Employers & Job Seekers
- Marathon, Florida Area Jobs and career opportunites

Add town community groups only if the job is clearly local and the group allows job posts.

### Housing Or Rental Post

Use only:
- Upper Fl Keys Rentals
- Florida Keys Forever Home

Add town community groups only if group rules allow housing posts.

### Environment, Water, Or Conservation Post

Use:
- Florida Bay Forever
- Florida Sargassum Reports + Daily News
- Pirates Saving Paradise Group, when cause-aligned
- Florida Keys Fishing, only if it affects anglers/boaters

### History Or Heritage Post

Use:
- Florida Keys History with Brad Bertelli

Add community groups only when it has broad local interest.

## Posting Rules

- Do not blast all 40 groups.
- Prefer 3-8 groups for normal posts.
- Use 8-12 groups only for strong Keys-wide announcements.
- Stagger posts 10-15 minutes apart.
- Change the first sentence per group bucket.
- Avoid identical links-only posts.
- Check promo rules before posting to any group.
- Keep a log of posted group, time, asset, and result.
